## 1. 项目概述

### 1.1 项目简介

GreenPulse 是一个新能源发电功率预测系统，支持超短期(UST)、短期(ST)、中期(MT)和次季节(SS)等多种时间尺度的预测。系统采用模块化设计，集成了多种先进的机器学习算法，为新能源发电场提供高精度的功率预测服务。

### 1.2 主要功能

- **多时间尺度预测**：支持从15分钟到数周的功率预测
- **高精度模型**：集成多种机器学习算法，包括深度学习模型
- **实时监控**：提供实时预测结果和性能监控
- **灵活配置**：支持模型参数和预测参数的灵活配置
- **可视化展示**：提供直观的预测结果可视化

### 1.3 技术栈

- **编程语言**：Python 3.12+
- **机器学习框架**：PyTorch
- **数据处理**：Pandas, NumPy
- **API 服务**：FastAPI
- **任务调度**：Celery
- **数据库**：PostgreSQL, InfluxDB
- **监控**：Prometheus, Grafana
- **容器化**：Docker, Kubernetes

## 2. 开发环境

### 2.1 环境要求

- **操作系统**：Linux
- **Python**：3.12+
- **CUDA**：11.8（如需GPU加速）
- **内存**：建议16GB或更高
- **存储**：建议50GB可用空间

### 2.2 环境配置

1. 克隆代码库：
   ```bash
   git clone http://221.122.67.135:8005/zhangyongpeng/greenpulse-gen.git
   cd greenpulse-gen
   ```

2. 创建并激活虚拟环境：
   ```bash
   # 使用 conda
   conda create -n greenpulse python=3.12
   conda activate greenpulse
   
   # 或使用 venv
   # python -m venv venv
   # source venv/bin/activate  # Linux/macOS
   ```

3. 安装依赖：
   ```bash
   # 安装 PyTorch (CUDA 11.8)
   conda install pytorch torchvision torchaudio pytorch-cuda=11.8 -c pytorch -c nvidia
   
   # 安装项目依赖
   pip install -r requirements.txt
   
   # 安装开发依赖（可选）
   pip install -r requirements-dev.txt
   ```

4. 配置环境变量：
   复制示例配置文件并修改：
   ```bash
   cp config/GreenPulse.develop.yaml config/GreenPulse.yaml
   ```
   根据实际情况修改 `config/GreenPulse.yaml` 中的配置项。

## 3. 项目结构

### 3.1 目录结构

```
.
├── config/             # 配置文件
├── data/               # 数据文件
├── doc/                # 文档
├── logs/               # 日志文件

│   ├── accuracy/       # 精度评估模块
│   ├── config/         # 配置管理
│   ├── datasets/       # 数据集处理
│   ├── modelset/       # 模型实现
│   │   ├── ST/         # 短期模型
│   │   ├── UST/        # 超短期模型
│   │   ├── base.py     # 模型基类
│   │   └── __init__.py # 模型加载器
│   ├── task.py         # 任务调度
│   ├── utils/          # 工具函数
│   ├── deploy.py       # 部署工具
│   ├── logger.py       # 日志模块
│   ├── message.py      # 消息队列
│   └── params.py       # 参数配置
├── tests/              # 单元测试
└── main.py             # 主程序入口
```

### 3.2 核心模块说明

- **modelset/**：模型实现目录，包含各种预测模型
  - `base.py`：定义模型基类接口
  - `ST/`：短期预测模型
  - `UST/`：超短期预测模型
  
- **datasets/**：数据处理模块
  - 数据加载、预处理、特征工程等
  
- **accuracy/**：精度评估模块
  - 实现各种评估指标
  - 生成评估报告
  
- **config/**：配置管理
  - 加载和解析配置文件
  - 管理配置项

## 4. 开发指南

### 4.1 代码规范

1. **代码风格**
   - 遵循 PEP 8 规范
   - 使用类型注解
   - 函数和变量使用下划线命名法（snake_case）
   - 类名使用驼峰命名法（CamelCase）

2. **文档规范**
   - 为所有公共API添加文档字符串
   - 使用 Google 风格文档字符串
   - 添加必要的注释说明复杂逻辑

3. **提交规范**
   - 遵循 Conventional Commits 规范
   - 提交信息格式：`<type>(<scope>): <description>`
   - 类型包括：feat, fix, docs, style, refactor, test, chore

### 4.2 开发流程

1. **创建特性分支**
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. **开发测试**
   - 编写单元测试
   - 运行测试确保通过
   - 更新文档

3. **提交代码**
   ```bash
   git add .
   git commit -m "feat(module): add new feature"
   git push origin feature/your-feature-name
   ```

4. **创建合并请求**
   - 在 GitLab 上创建合并请求到 develop 分支
   - 等待代码审查
   - 解决代码审查意见
   - 合并到 develop 分支

### 4.3 测试规范

1. **单元测试**
   - 为所有公共API编写单元测试
   - 测试覆盖率应达到80%以上
   - 使用 pytest 框架

2. **运行测试**
   ```bash
   # 运行所有测试
   pytest tests/
   
   # 运行特定测试文件
   pytest tests/test_modelset.py
   
   # 生成覆盖率报告
   pytest --cov=src tests/
   ```

3. **代码质量检查**
   ```bash
   # 代码风格检查
   flake8 src/
   
   # 类型检查
   mypy src/
   
   # 代码复杂度检查
   radon cc src/
   ```

## 5. 模型开发

### 5.1 模型接口规范

所有模型必须继承自 `BaseModel` 类并实现以下方法：

```python
class BaseModel(ABC):
    @abstractmethod
    def train(self, train_data, val_data=None, **kwargs):
        """训练模型"""
        pass
    
    @abstractmethod
    def predict(self, input_data, **kwargs):
        """使用模型进行预测"""
        pass
    
    @abstractmethod
    def save(self, model_path):
        """保存模型"""
        pass
    
    @classmethod
    @abstractmethod
    def load(cls, model_path):
        """加载模型"""
        pass
```

### 5.2 添加新模型

1. 在 `modelset/` 下创建新模型文件，例如 `modelset/ST/your_model.py`
2. 实现模型类，继承自 `BaseModel`
3. 在 `modelset/__init__.py` 中注册新模型
4. 添加单元测试
5. 更新文档

### 5.3 模型评估

模型评估指标包括：
- 均方根误差 (RMSE)
- 平均绝对误差 (MAE)
- 平均绝对百分比误差 (MAPE)
- 相关系数 (R²)

## 8. 常见问题

### 8.1 依赖安装问题

**问题**：安装 PyTorch 时出错  
**解决**：根据 CUDA 版本选择合适的 PyTorch 安装命令：
```bash
# CUDA 11.8
conda install pytorch torchvision torchaudio pytorch-cuda=11.8 -c pytorch -c nvidia

# CPU 版本
conda install pytorch torchvision torchaudio cpuonly -c pytorch
```

### 8.2 模型训练问题

**问题**：训练时显存不足  
**解决**：
1. 减小 batch_size
2. 使用混合精度训练
3. 使用梯度累积

### 8.3 性能优化

1. 使用 Dask 或 Ray 进行分布式训练
2. 使用 ONNX 加速模型推理
3. 优化数据加载管道
