## 数据加载与保存接口约定

### 1. 概述

本模块提供了统一的数据加载和保存接口，支持从多种数据源（CSV、NetCDF、PostgreSQL）加载数据，以及将数据保存到文件系统。同时提供了模型加密保存和加载的功能，确保模型安全。


### 2. 数据格式约定

#### 2.1 通用数据格式

1. **时间序列数据**
   - 类型：`pandas.DataFrame`
   - 索引：`pandas.DatetimeIndex`，时区为UTC
   - 缺失值：使用`numpy.nan`表示
   - 示例：
     ```python
     # 时间序列数据示例
     # index: DatetimeIndex
     # columns: ['temperature', 'humidity', 'wind_speed']
     # values: float64
     ```

2. **模型数据**
   - 类型：`bytes`（加密后）或任意可序列化Python对象（解密后）
   - 加密：使用AES-256-GCM算法
   - 序列化：使用pickle协议4

3. **错误响应**
   - 类型：`Dict[str, Any]`
   - 必填字段：
     - `success`: `bool` - 操作是否成功
     - `error`: `str` - 错误信息（操作失败时）
     - `data`: `Any` - 返回数据（操作成功时）
   - 示例：
     ```python
     # 成功响应
     {
         "success": True,
         "data": {...}
     }
     
     # 错误响应
     {
         "success": False,
         "error": "File not found: data.csv"
     }
     ```

### 2.2 数据加载器 (CDataLoader)

`CDataLoader` 类提供了统一的数据加载接口，支持从多种数据源加载气象和功率数据。

                    'data_element2': pd.DataFrame(...),
                    ...
                },
                'data_source2': {...},
                ...
            },
            'timeliness2': {...},
            ...
        },
        ...

其中 `station` 为站点，`timeliness` 为时效性，`data_source` 为数据源，`data_element` 为数据元素。

### 4. 错误处理

所有数据加载和保存函数都实现了完善的错误处理机制，主要包括以下异常：

- `FileNotFoundError`: 当文件或目录不存在时抛出
- `PermissionError`: 当没有文件读写权限时抛出
- `ValueError`: 当参数无效或数据格式错误时抛出
- `psycopg2.Error`: 当数据库操作失败时抛出
- `cryptography.fernet.InvalidToken`: 当解密失败时抛出
- `pickle.UnpicklingError`: 当反序列化失败时抛出

### 5. 日志记录

所有函数都接受一个 `logger` 参数用于记录操作日志，建议在生产环境中配置适当的日志级别和处理器。

### 6. 线程安全

- 文件操作：所有文件操作都是原子的，支持多线程并发访问
- 日志记录：`logging` 模块是线程安全的

## 准确率评估接口约定

### 1. 基本概念

准确率评估模块提供了统一的接口来评估预测模型的准确率。该模块基于抽象基类 `BaseAccuracy` 实现，支持多种评估指标（如 MAE、RMSE、MAPE 等）和时间尺度（超短期、短期、中期、次季节等）。

### 2. 接口定义

#### 2.1 基类接口

所有准确率评估类都应继承自 `BaseAccuracy` 基类，并实现以下方法：

```python
class BaseAccuracy(ABC):
    @abstractmethod
    def __init__(self, staParam: CStaParams, **kwargs):
        """
        初始化准确率评估器
        
        参数:
            staParam: 站点参数对象
            **kwargs: 其他可选参数
        """
        pass

    @abstractmethod
    def ust_day(self, pred: dict[pd.Timestamp, pd.Series], obs: pd.Series, 
               logger: logging.Logger, **kwargs) -> dict[pd.Timestamp, dict[str, float]]:
        """
        计算超短期日尺度准确率
        
        参数:
            pred: 预测值字典，键为时间戳，值为预测序列
            obs: 观测值序列
            logger: 日志记录器
            **kwargs: 其他可选参数
            
        返回:
            包含准确率结果的字典，格式为 {时间戳: {"acc": 准确率, "score": 分数}}
        """
        pass

    # 其他方法: ust_month, st_day, st_month 参数和返回值与 ust_day 类似
```

#### 2.2 方法说明

1. **初始化方法**
   - `__init__(staParam, **kwargs)`: 初始化评估器，接收站点参数和可选配置

2. **评估方法**
   - `ust_day()`: 超短期日尺度评估
   - `ust_month()`: 超短期月尺度评估
   - `st_day()`: 短期日尺度评估
   - `st_month()`: 短期月尺度评估

#### 2.3 参数说明

- `pred`: 预测值字典
  - 类型: `dict[pd.Timestamp, pd.Series]`
  - 键为任务日期，值为该日期的预测序列
  - 预测序列的索引应为时间戳

- `obs`: 观测值序列
  - 类型: `pd.Series`
  - 索引应为时间戳，与预测序列的时间戳对应

- `logger`: 日志记录器
  - 类型: `logging.Logger`
  - 用于记录评估过程中的日志信息

### 3. 实现示例

以下是 MAE (平均绝对误差) 评估器的实现示例：

```python
class MAE(BaseAccuracy):
    def __init__(self, staParam: CStaParams, **kwargs):
        super().__init__(staParam, **kwargs)
        # 初始化代码

    def ust_day(self, pred, obs, logger, **kwargs):
        result = {}
        for task_date, pred_series in pred.items():
            obs_series = obs[obs.index.isin(pred_series.index)]
            mae_value = np.mean(np.abs(pred_series - obs_series))
            result[task_date] = {"acc": mae_value, "score": np.nan}
        return result
    
    # 其他方法实现...
```

### 4. 返回值格式

所有评估方法返回一个字典，格式为：

```python
{
    pd.Timestamp("2023-01-01"): {
        "acc": 0.95,  # 准确率值
        "score": 100   # 分数（可选）
    },
    # 其他日期...
}
```

## 算法加载接口约定

### 1. 概述

本规范定义了算法模型的加载、初始化和使用接口，支持按时间维度和算法类型动态加载模型。系统采用工厂模式实现模型的动态加载，通过统一的接口管理不同时间维度的预测模型。

### 2. 核心接口

#### 2.1 模型加载接口

```python
def modelget(
    staParam: CStaParams, 
    timeLiness: TimeLiness, 
    algorithm: str, 
    version: Optional[str] = None, 
    **kwargs
) -> BaseModel:
    """获取指定配置的模型实例
    
    参数:
        staParam (CStaParams): 站点参数对象，包含站点配置信息
        timeLiness (TimeLiness): 时效类型枚举，如 TimeLiness.ST（短期）
        algorithm (str): 算法名称，对应模块文件名（不含.py）
        version (str, optional): 模型版本，默认使用algorithm作为版本名
        **kwargs: 传递给模型构造函数的其他参数
    
    返回:
        BaseModel: 初始化后的模型实例

        AttributeError: 当指定的版本在模块中不存在时抛出
        ImportError: 当无法加载指定的算法模块时抛出
    """
```

#### 2.2 模型基类接口

所有算法模型必须继承自 `BaseModel` 并实现以下接口：

```python
class BaseModel(ABC):
    """模型基类，定义所有模型必须实现的接口"""
    
    @abstractmethod
    def __init__(self, staParam: CStaParams, **kwargs):
        """初始化模型
        
        参数:
            staParam (CStaParams): 站点参数
            **kwargs: 其他模型参数
        """
        pass
    
    @abstractmethod
    def load(self, model, patternLogger: logging.Logger) -> None:
        """加载模型
        
        参数:
            model: 模型对象
            patternLogger: 日志记录器
        """
        pass
    
    @abstractmethod
    def predict(self, X: dict, taskDate: pd.Timestamp, staParam: CStaParams, 
                patternLogger: logging.Logger, dataLoader: CDataLoader, **kwargs) -> pd.DataFrame:
        """执行预测
        
        参数:
            X (dict): 输入特征数据
            taskDate (pd.Timestamp): 预测日期
            staParam (CStaParams): 站点参数
            patternLogger: 日志记录器
            dataLoader: 数据加载器
            **kwargs: 其他预测参数
            
        返回:
            pd.DataFrame: 预测结果
        """
        pass
    
    @abstractmethod
    def train(self, X: dict, Y: dict, taskDateList: list[pd.Timestamp], 
              staParam: CStaParams, patternLogger: logging.Logger, 
              dataLoader: CDataLoader, **kwargs) -> Any:
        """训练模型
        
        参数:
            X (dict): 训练特征数据
            Y (dict): 训练标签数据
            taskDateList (list): 训练日期列表
            staParam (CStaParams): 站点参数
            patternLogger: 日志记录器
            dataLoader: 数据加载器
            **kwargs: 其他训练参数
        """
        pass
    
    @abstractmethod
    def tuning(self, X: dict, Y: dict, taskDateList: list[pd.Timestamp], 
               staParam: CStaParams, patternLogger: logging.Logger, 
               dataLoader: CDataLoader, **kwargs) -> Any:
        """模型调优
        
        参数:
            X (dict): 调优特征数据
            Y (dict): 调优标签数据
            taskDateList (list): 调优日期列表
            staParam (CStaParams): 站点参数
            patternLogger: 日志记录器
            dataLoader: 数据加载器
            **kwargs: 其他调优参数
        """
        pass
```

### 5. 错误处理

- 模型加载失败时应抛出明确的异常信息
- 预测过程中应捕获并记录异常
- 资源使用应有超时和清理机制

### 6. 性能要求

- 模型加载时间应控制在合理范围内
- 预测接口应支持批量处理
- 应考虑模型的内存占用和计算效率

### 7. 日志规范

- 关键操作需要记录日志
- 日志应包含时间戳、模块名、日志级别和详细信息
- 敏感信息不应记录在日志中

## 后处理接口约定

### 1. 概述
本文档定义了风光功率预测模型中的后处理接口规范，适用于MT（中短期预测）、ST（短期预测）和 UST（超短期预测）等预测模型。后处理接口主要用于对模型预测结果进行修正和优化，以提高预测精度。

### 2. 后处理基类接口

### 2.1 BasePostProcessor 基类
```python
class BasePostProcessor(ABC):
    """模型后处理基类"""
    
    @abstractmethod
    def __init__(self, staParam: CStaParams, **kwargs):
        """
        初始化模型后处理器
        
        参数:
            staParam (CStaParams): 站点参数对象
            **kwargs: 其他可选参数
        """
        
    @abstractmethod
    def load(self, model, patternLogger: logging.Logger) -> None:
        """
        加载后处理模型
        
        参数:
            model: 模型对象
            patternLogger: 日志记录器
        """
        
    @abstractmethod
    def fit(self, X, Y, taskDateList: list[pd.Timestamp], patternLogger: logging.Logger, **kwargs):
        """
        后处理参数选优
        
        参数:
            X: 模型预测数据
            Y: 考核基准数据
            taskDateList: 训练日期列表
            patternLogger: 日志记录器
            **kwargs: 其他可选参数
        """
        
    @abstractmethod
    def transform(self, X, patternLogger: logging.Logger, **kwargs):
        """
        对预测数据进行后处理
        
        参数:
            X: 模型预测数据
            patternLogger: 日志记录器
            **kwargs: 其他可选参数
            
        返回:
            后处理后的预测结果
        """
```

### 3. 后处理数据格式约定

输入预测数据格式为：

```python
Dict[str, Dict[str, Dict[str, Dict[str, pd.DataFrame]]]]
    # 嵌套字典结构，包含加载和处理后的预测功率数据，格式为:

                    ...
                }
            },
            'timeliness2': {...},
            ...
        },
        ...
    }
```

返回约定，返回 pd.DataFrame：

如果为 光伏站点，功率数据保存格式为:

```csv
time,power,radi,ghi_pw,poa_pw
2025-06-19 16:00:00+00:00,0.0,0.0,0.0,0.0
```

如果为 风力站点，功率数据保存格式为:

```csv
time,power,wind
2025-06-19 16:00:00+00:00,0.0,0.0
```

PS：时间索引需保留时区信息。

### 4. 注意事项

1. 后处理参数应根据具体场站特性进行调整
2. 功率曲线应定期更新以反映设备性能变化
3. 异常值处理参数需要根据历史数据进行优化
4. 后处理过程中应记录关键参数和处理结果，便于问题追踪和效果评估
