## 模型开发手册

该模块定义了模型基类，提供了一个通用的模型接口，任何具体的模型都可以继承该基类并实现其中的抽象方法，以便在不同的应用场景中进行模型训练、预测、保存和加载操作。

### 使用方法

- 继承模型基类，并实现其中的抽象方法。
  可以创建新的模型类，并根据需求实现模型基类中定义的抽象方法。这样可以确保模型能够兼容现有的模型接口，并可以无缝地与其他代码集成。

```python
class regressor(base.BaseModel):
    def __init__(self):
        #... 具体的实现
```

- 添加模块导出接口。
  在模块初始化入口添加对应的导出接口，以便模型可以被其他模块和代码所使用。

```python
__init__.py

from modelset.regressor import regressor
```

- 添加模型配置参数

- 使用子类对象进行模型的初始化、训练、预测、保存和加载操作。
  一旦创建了模型子类的对象，就可以使用这些对象执行模型的各种操作，包括初始化、训练、预测、保存和加载等。

### 接口说明

模型基类，定义了以下抽象方法：

#### 初始化方法

```python
__init__(self, params, **kwargs)
```

参数：

- params: 模型初始化所需的参数。
- \*\*kwargs: 其他可选参数。

#### 训练方法

```python
train(self, train_data, val_data, **kwargs)
```

参数：

- train_data: 用于模型训练的训练数据。
- val_data: 用于模型训练的验证数据。
- \*\*kwargs: 其他可选参数。

#### 预测方法

```python
predict(self, data, **kwargs)
```

参数：

- data: 待预测的数据。
- \*\*kwargs: 其他可选参数。

#### 模型保存

```python
dump(self, file_path, **kwargs)
```

参数：

- file_path: 保存模型的文件路径。
- \*\*kwargs: 其他可选参数。

#### 模型加载

```python
load(self, file_path, **kwargs)
```

参数：

- file_path: 加载模型的文件路径。
- \*\*kwargs: 其他可选参数。

### 示例

#### 模型类

```python
import catboost
import joblib
import modelset.base as base


class regressor(base.BaseModel):
    """
    模型类, 继承自 base.model
    """

    def __init__(self, params, **kwargs):
        self.model = catboost.CatBoostRegressor(
            iterations=params.findtext("iterations"),
            depth=params.findtext("depth"),
            learning_rate=params.findtext("learning_rate"),
            loss_function=params.findtext("loss_function"),
            eval_metric=params.findtext("eval_metric"),
            verbose=params.findtext("verbose"),
            subsample=params.findtext("subsample"),
            early_stopping_rounds=params.findtext("early_stopping_rounds"),
            colsample_bylevel=params.findtext("colsample_bylevel"),
            **kwargs,
        )

    def predict(self, data, **kwargs):
        return self.model.predict(data, **kwargs)

    def train(self, train_data, val_data, **kwargs):
        feats = kwargs.get("feats", None)
        if feats is None:
            raise RuntimeError("feats is None")
        kwargs.pop("feats")

        self.model.fit(
            train_data.loc[:, feats],
            train_data.loc[:, "Power"],
            eval_set=(val_data.loc[:, feats], val_data.loc[:, "Power"]),
            **kwargs,
        )

    def dump(self, file_path, **kwarg):
        joblib.dump(self.model, file_path, **kwarg)

    def load(self, file_path, **kwarg):
        return joblib.load(file_path, **kwarg)
```

### 注意事项

1. 所有的子类必须实现基类中定义的所有抽象方法，否则会抛出异常。
   确保模型子类实现了基类中定义的所有抽象方法，否则可能会导致运行时错误。
2. 在子类中可以根据具体需求添加额外的方法和属性。
   可以根据模型的特定需求添加额外的方法和属性，以增强模型的功能和灵活性。
3. 在使用模型时，务必确保传入的数据格式和参数与模型的要求一致。
   在使用模型进行训练和预测时，确保传入的数据格式和参数与模型的要求一致，以避免出现意外错误。
