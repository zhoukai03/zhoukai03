## 工作流程开发手册

请**按功能模块化编写**，方便后续维护，这很重要。

各个模块请提供一个主流程入口, 参考如下

```python
main(cfg: xml.etree.ElementTree.Element, **kwargs)
```

其中 `cfg` 参数是配置文件，**请在主流程入口处定义**，**不要在其他地方引用**，否则会造成配置文件的引用冲突。
`cfg` 类型为 `xml.etree.ElementTree.Element`, 例如 `ET.parse(self.path).getroot()`.
可通过 `cfg.find() / cfg.findtext()` 方法获取配置文件中的元素。例如

```python
base_path = cfg.findtext('base_path')
```

各个模块须自行定义独立运行流程，但统一采用有 `main` 模块提供的日志器和参数解析器。参考如下

```python
import main as luncher

if __name__ == "__main__":
    try:
        logger = luncher.set_logger()
        args = luncher.get_args()
        main(args) # 你的主流程入口
    except Exception as e:
        logger.exception(e)
        exit(1)
```
