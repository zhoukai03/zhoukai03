## 1. 快速开始

### 1.1 安装

```bash
# 克隆代码库
git clone http://221.122.67.135:8005/zhangyongpeng/greenpulse-gen.git
cd greenpulse-gen

# 创建并激活虚拟环境
conda create -n greenpulse python=3.12
conda activate greenpulse

# 安装依赖
pip install -r requirements.txt
```

### 1.2 配置

1. 复制配置文件：
   ```bash
   cp config/GreenPulse.develop.yaml config/GreenPulse.yaml
   ```

2. 编辑 `config/GreenPulse.yaml`，配置数据库连接、消息队列等参数。

### 1.3 运行示例

```bash
# 查看帮助
python main.py -h

# 运行超短期预测（单站）
python main.py -f fc --timeliness UST --staListType single --staListFile config/station_list.csv
```

## 2. 命令详解

### 2.1 基本命令

| 参数 | 缩写 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--config` | `-c` | 否 | `config/GreenPulse.yaml` | 配置文件路径 |
| `--logLevel` | `-l` | 否 | `INFO` | 日志级别 |
| `--taskID` | - | 否 | 自动生成 | 任务ID |

### 2.2 任务类型

| 任务类型 | 参数值 | 说明 |
|---------|-------|------|
| 预测 | `fc` | 执行预测任务 |
| 历史预测 | `hfc` | 执行历史数据回算 |
| 重新训练 | `ft` | 重新训练模型 |
| 更新训练 | `upt` | 增量更新模型 |

### 2.3 数据源配置

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `--dataSet` | 否 | `EC_IFS` | 气象数据源 |
| `--staListType` | 是 | - | 站点类型：`single`(单站)/`area`(区域) |
| `--staListFile` | 是 | - | 站点清单文件路径 |
| `--timeliness` | 是 | - | 预测时效：`UST`/`ST`/`MT`/`SS` |

### 2.4 算法选择

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `--algorithm` | 否 | `catboost` | 算法选择 |
| `--postProcess` | 否 | - | 后处理算法 |
| `--accuracy` | 否 | - | 精度评估算法 |

### 2.5 资源控制

| 参数 | 说明 |
|------|------|
| `--cpu` | CPU核心数 |
| `--gpu` | GPU数量 |
| `--cmem` | CPU内存(MB) |
| `--gmem` | GPU显存(MB) |
| `--node` | 节点数 |

## 3. 使用示例

### 3.1 单站预测

```bash
# 单站超短期预测
python main.py -f fc \
  --timeliness UST \
  --staListType single \
  --staListFile config/station_list.csv \
  --algorithm catboost \
  --dataSet EC_IFS
```

### 3.2 区域预测

```bash
# 区域短期预测
python main.py -f fc \
  --timeliness ST \
  --staListType area \
  --staListFile config/area_list.csv \
  --algorithm LSTM \
  --gpu 1 \
  --gmem 8000
```

### 3.3 模型训练

```bash
# 重新训练模型
python main.py -f ft \
  --timeliness ST \
  --staListType area \
  --staListFile config/area_list.csv \
  --algorithm transformer \
  --gpu 1
```

### 3.4 历史回算

```bash
# 历史数据回算
python main.py -f hfc \
  --timeliness ST \
  --staListType area \
  --staListFile config/area_list.csv \
  --dateRange 20230101 20231231 \
  --algorithm catboost
```

## 4. 输出说明

### 4.1 输出目录结构

```
output/
├── {task_id}/
│   ├── config/          # 配置文件
│   ├── logs/            # 日志文件
│   ├── models/          # 模型文件
│   ├── results/         # 预测结果
│   │   ├── csv/         # CSV格式结果
│   │   └── figure/      # 可视化图表
│   └── evaluation/      # 评估报告
```

### 4.2 结果文件格式

预测结果CSV文件包含以下字段：
- `station_id`: 站点ID
- `time`: 时间戳
- `prediction`: 预测值
- `ground_truth`: 真实值（如果可用）
- `confidence`: 置信度

## 5. 常见问题

### 5.1 依赖安装失败

**问题**：安装PyTorch时出错  
**解决**：根据CUDA版本安装对应版本的PyTorch：
```bash
# CUDA 11.8
conda install pytorch torchvision torchaudio pytorch-cuda=11.8 -c pytorch -c nvidia
```

### 5.2 内存不足

**问题**：运行时报内存不足错误  
**解决**：
1. 减小批量大小
2. 使用`--cmem`参数限制内存使用
3. 使用更小的模型

### 5.3 预测结果异常

**问题**：预测结果不准确  
**解决**：
1. 检查输入数据质量
2. 尝试不同的算法
3. 调整模型参数

### 5.4 性能优化

1. 使用GPU加速：添加`--gpu 1`参数
2. 增加并行度：调整`--cpu`参数
3. 使用混合精度训练：在配置文件中设置`use_amp: true`
